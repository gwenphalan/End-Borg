# End-Borg

Personal desktop fork of [end-4/dots-hyprland](https://github.com/end-4/dots-hyprland),
rebased onto upstream main with Gwen's Quickshell and Hyprland customizations.
Upstream GPL-3.0 licensing and bundled asset licenses remain in effect.

Includes Spotlight, desktop Settings, Home Assistant/Bed Lock and Music Assistant,
Borg Intelligence, adaptive app icons, clock fonts, Lens Cap and the shared tool-app
framework, recording, monitor controls, and editor palette synchronization.

Start with [the consolidation record](docs/CONSOLIDATION.md),
[validation](docs/VALIDATION.md), and [deployment](docs/DEPLOYMENT.md).
Do not use the inherited `setup` script to migrate an existing customized desktop.

Personal settings, credentials, keyring entries, documents and runtime state stay
outside Git. The repo is the source tree; the live desktop remains a separate copy.
